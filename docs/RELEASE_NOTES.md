# AutoSim Studio (ICAN) 1.2.10

**Download** (Windows 10 / 11, 64-bit): `AutoSim Studio_1.2.10_x64-setup.exe`. It installs over 1.2.x and keeps
settings, databases, groups, rules, Test APIs and trace filters.

## Changed

- **One background in Simulation.** The Interactive generator had a grey background around its groups; it is now the
  same as Auto response and Trace (white, or the dark panel colour in the dark theme).

See [1.2.9](RELEASE_NOTES_1.2.9.md) for the fix of the second (Windows) title bar after an update.
