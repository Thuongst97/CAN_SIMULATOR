AutoSim VHAL Bridge

The whole path of a CAN frame: from the VHAL in the head unit's Android VM, through autosim-bridge and adb, to AutoSim on the PC, and the rule's response frame back. The VHAL is not modified: it still opens can0, only can0 is now a vcan. The first section places this approach in Android's CAN layers.

CAN layers in Android and where AutoSim steps in

A command from an app goes down to the bus through 7 layers. Each arrow says how the two layers talk: Binder between processes, socket syscalls between user space and the kernel, the driver API inside the kernel, then registers or a virtqueue down to the hardware. The right-hand column lists the places where a simulation can step in.
